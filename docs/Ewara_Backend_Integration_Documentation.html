5. JWT Auth System

Tokens

  • Access Token: 15min expiry, stateless
  • Refresh Token: 7 days, stored HttpOnly cookie
  • Payload: { userId, email/phone, role }

RBAC Middleware

const requireRole = (role) => (req, res, next) => {
  if (req.user.role !== role) {
    return res.status(403).json({ error: 'Access denied' });
  }
  next();
};

// Usage
router.post('/products', requireRole('admin'), createProduct);

6. Payment System (Razorpay)

Create Razorpay Order

POST /orders → Returns razorpay_order_id
Frontend: razorpay.open({ order_id })

Webhook POST /payment/webhook:
- Verify signature
- Update order paymentStatus = 'paid'
- Change order status → 'shipped'
